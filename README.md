# P.A.C.T. Gatekeeper: Isolated Asymmetric Tool-Execution Interceptor

Deterministic, out-of-process execution gate for autonomous AI agent tool invocation.

## Target Vulnerability Coverage (OWASP Agentic Security Initiative)
* **ASI02: Tool Misuse and Exploitation** — Mitigated via out-of-process Euclidean parameter vector clamping.
* **ASI03: Identity & Privilege Abuse** — Mitigated by eliminating ambient agent authority and requiring payload-bound asymmetric (Ed25519) signatures for high-impact actions.

---

## Abstract & Architecture

The **P.A.C.T. Gatekeeper** decouples AI agent reasoning from state-mutating execution environments. Rather than granting autonomous agents ambient credentials to execute shell commands, database queries, or financial transactions, all tool invocations are treated as unprivileged **Intent Proposals**.

```text
[ Compromised Agent / LLM ]
           │
           ▼ (Tool Call Proposal: name, parameters)
┌────────────────────────────────────────────────────────┐
│ P.A.C.T. EXECUTION GATE (Layer 6 Proxy / Sidecar)      │
│                                                        │
│ 1. Parameter Digest: SHA-256(tool_name + raw_params)   │
│ 2. Blast Radius: ||v|| = sqrt(r² + w² + f²)            │
│                                                        │
│   ├─ If ||v|| <= Ceiling ──► [ Autonomous Execution ]  │
│   └─ If ||v|| >  Ceiling ──► [ Require Ed25519 Token ] │
└────────────────────────────────────────────────────────┘
           │
           ▼
[ Hardware / Human Signer (Partner's Key) ]
```

### 1. Euclidean Blast Radius Clamping
Parameters are classified across three independent risk axes:
* **r (Read Volume):** 0.0 to 1.0 (Data exposure / exfiltration risk)
* **w (Write Scope):** 0.0 to 1.0 (State mutation / system modification risk)
* **f (Financial Impact):** 0.0 to 1.0 (Transaction size or direct compute cost)

The composite magnitude is evaluated deterministically:
$$\|\vec{v}\| = \sqrt{r^2 + w^2 + f^2}$$

If $\|\vec{v}\|$ exceeds the configured `autonomous_ceiling`, execution is immediately interrupted.

### 2. Payload-Bound Ephemeral Authorization
When a proposal breaches the autonomous ceiling:
1. The Gate computes a deterministic SHA-256 digest of the tool name and exact parameters.
2. The Gate halts execution and emits an `EscalateToSigner` challenge containing the digest.
3. The action cannot proceed without a valid Ed25519 digital signature generated by the human operator's private key over that exact digest. Replayed tokens or modified parameters are rejected.

## MAESTRO 7-Layer Threat Model Mapping

* **Layer 6 (Security & Compliance):** Primary policy-gate enforcement. Restricts Non-Human Identity (NHI) scope and deterministically enforces dynamic authorization.
* **Layer 4 (Deployment & Infrastructure):** Hardened, compiled Rust binary running as an isolated sidecar or IPC proxy, preventing runtime memory corruption or prompt-injection bypasses.
